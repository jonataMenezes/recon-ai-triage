**Recon AI Triage** is an advanced Python-based security tool designed for offensive security researchers and Bug Bounty hunters. Its primary mission is to filter the massive noise generated by reconnaissance tools, using a sophisticated scoring and correlation engine to prioritize assets with the highest potential for exploitation.

By analyzing outputs from **Nmap**, **FFUF**, and generic system logs, the tool classifies findings into three distinct levels:
* **Noise:** Common findings with negligible security risk.
* **Interesting:** Assets that show signs of misconfiguration and deserve manual review.
* **Potential Vulnerability:** Critical flaws or direct exposures that require immediate action.

## 🚀 Key Features (v1.1.1)

* **Automated CVE Enrichment:** Native integration with the **NVD API v2.0 (NIST)** to automatically fetch known vulnerabilities based on detected products and versions.
* **Intelligent Correlation Engine:** Identifies dangerous patterns, such as protected administrative panels (401/403) appearing alongside exposed database services.
* **Debian/Linux Optimization:** Refined code logic ensuring maximum stability and performance on standard Linux distributions and triage servers.
* **YAML-Driven Configuration:** Full flexibility to define critical keywords, risky ports, and scoring thresholds via the `config.yaml` file.
* **LLM-Assisted Analysis (Optional):** Optional integration with OpenAI models to provide a deep semantic analysis layer over the findings.

## 🛠️ Installation

```bash
# Clone the repository
git clone [https://github.com/jonataMenezes/recon-ai-triage.git](https://github.com/jonataMenezes/recon-ai-triage.git)
cd recon-ai-triage

# Set up virtual environment
python3 -m venv venv
source venv/bin/activate

# Install updated dependencies
pip install -r requirements.txt

```

## 📖 Usage

### Triage with CVE Enrichment (Recommended)

```bash
python triage.py -i inputs/nmap.xml --cve --no-llm

```

### Full Triage (AI + CVE Enrichment)

```bash
export OPENAI_API_KEY='your_api_key_here'
python triage.py -i inputs/ffuf.json --cve

```

## 📂 Output Structure

Reports are automatically generated in the `outputs/` directory:

1. **`findings.json`**: Structured data ready for integration with other automation pipelines.
2. **`findings.md`**: A clean, human-readable Markdown report optimized for documenting Proof of Concepts (PoCs).
